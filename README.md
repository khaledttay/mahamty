# مهمتي - نسخة أندرويد (APK)
1. اعمل حساب على github.com وأنشئ مستودع جديد باسم mahamty (Public).
2. فك الضغط، وفي المستودع: Add file ← Upload files، واسحب كل محتويات الفولدر (بما فيها فولدر .github لو ظهر).
3. لو تبويب Actions مفيهوش workflow اسمه Build APK: Add file ← Create new file، اكتب الاسم .github/workflows/build-apk.yml والصق محتوى build-apk.yml.
4. تبويب Actions ← Build APK ← Run workflow. استنى 5 إلى 10 دقايق لحد ما يبقى أخضر.
5. افتح التشغيل الناجح، ونزّل mahamty-apk من Artifacts (ملف zip)، وفك الضغط لتطلع app-debug.apk.
6. ابعته لموبايلك وثبّته (اسمح بالتثبيت من مصدر غير معروف).
7. افتح التطبيق، اسمح بالإشعارات، واسمح بالمنبّهات الدقيقة لو طلب. من الإعدادات جرّب «تجربة منبّه الموبايل» واقفل الشاشة.
8. من إعدادات الموبايل ← التطبيقات ← مهمتي ← البطارية: اختار «بدون قيود».
